# 🌸 Gul Do'koni Boshqaruv Ilovasi

Python va Tkinter yordamida yaratilgan zamonaviy va qulay **Gul do'koni** grafik ilovasi (Desktop GUI).

---

## 🌟 Asosiy Imkoniyatlar

1. **💐 Gullar Katalogi va Qidiruv**:
   - Gullar ro'yxati, narxlari va ombordagi mavjud soni.
   - Kategoriya bo'yicha saralash (Atirgullar, Lolalar, Orkideyalar, Guldastalar va h.k.).
   - Nom yoki tavsif bo'yicha jonli qidirish.
   - Tanlangan gul haqida to'liq kartochka va rasmli/emojili ko'rinish.

2. **🛒 Savatcha va Buyurtma Rasmiylashtirish**:
   - Istalgan guldan kerakli miqdorda savatchaga qo'shish.
   - Buyurtmachi ismi, telefon raqami, manzili va tabriknoma yozish imkoniyati.
   - Umumiy summani avtomatik hisob-kitob qilish.
   - Buyurtma qilinganda ombordagi qoldiqdan avtomatik chegirish.

3. **⚙️ Boshqaruv (Admin Paneli)**:
   - Yangi gullar qo'shish (nomi, narxi, ombor soni, toifasi, tavsifi).
   - Mavjud gullar narxi yoki sonini tahrirlash.
   - Ro'yxatdan gullarni o'chirish.

4. **📜 Buyurtmalar Tarixi**:
   - Barcha tushgan buyurtmalar ro'yxati va holati.
   - Jami tushum va sotuvlar statistikasi.
